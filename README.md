# Modno Home

Интернет-витрина производителя модульных диванов: каталог моделей, страница каждого дивана с комплектацией и размерами, галереи фото и видео, формы заявок с отправкой на почту. Весь контент — тексты, цены, фото, телефоны — редактируется через админку Payload CMS без правок кода.

Продакшн: [modno-home.vercel.app](https://modno-home.vercel.app)

## Стек

- **Next.js 16** (App Router) + **React 19**
- **Payload CMS 3** + **MongoDB** — контент и админка
- **Tailwind CSS 4**, **TypeScript 5**
- **S3-совместимое хранилище** (Yandex Cloud Object Storage) — медиафайлы
- **Resend** — письма с заявками
- `keen-slider` — слайдеры, `yet-another-react-lightbox` — галерея

## Страницы

| Маршрут                 | Что это                                    |
| ----------------------- | ------------------------------------------ |
| `/`                     | Главная: hero, каталог, видео, отзывы      |
| `/sofa/[slug]`          | Страница модели дивана                     |
| `/privacy-policy`       | Политика конфиденциальности                |
| `/admin`                | Админка Payload                            |
| `/api/[...slug]`        | REST и GraphQL API Payload                 |
| `/api/form-submissions` | Приём заявок из форм → письмо на почту     |

`robots.ts` и `sitemap.ts` генерируются автоматически.

## Модель контента

**Коллекции**

- `Sofas` — модели диванов. Вкладки в админке: *Основная информация*, *Hero секция*, *Showcase секция*, *Комплектация*. Ключевые поля: название, категория, цена и старая цена, флаг `isActive` (показывать на сайте), изображение карточки, галерея слайдера, комплектация и размеры.
- `Media` — все загруженные файлы, хранятся в S3.
- `Users` — доступ в админку.

**Глобалы**

- `Home` — контент главной: заголовки hero, описания, тексты кнопок, секции.
- `Settings` — шапка сайта: телефон, часы работы, текст рядом с логотипом, видео в хедере.

> Фото диванов могут браться двумя способами: из загруженной галереи `viewImages` или из статической папки `public/sofas/<folderName>/`. Если галерея заполнена — приоритет у неё, а поле `viewsCount` игнорируется как устаревшее.

## Формы заявок

Все формы уходят в один обработчик `POST /api/form-submissions`, который отправляет письмо через Resend на адрес из `CONTACT_EMAIL`. Типы заявок: обратный звонок, запрос каталога, расчёт стоимости, вопрос о тканях и цветах. Обязательное поле одно — телефон.

> Отправитель зашит в коде как `Modno Home <info@modnohome.ru>`. Этот домен должен быть подтверждён в Resend, иначе письма не уйдут.

## Запуск

### Вариант A — локально

```bash
pnpm install
pnpm generate:types
pnpm generate:importmap
pnpm dev
```

Нужен MongoDB — локальный или Atlas, адрес указывается в `DATABASE_URI`.

### Вариант B — Docker

```bash
docker-compose up
```

Поднимет MongoDB и Next.js вместе. В этом режиме хост базы — `mongo`, то есть `DATABASE_URI=mongodb://mongo:27017/modno-home`. Снаружи Mongo доступна на порту `27018`.

Сайт — [localhost:3000](http://localhost:3000), админка — [localhost:3000/admin](http://localhost:3000/admin).

## Переменные окружения

Файла `.env.example` в репозитории нет — создай `.env` вручную с этими переменными.

| Переменная                  | Назначение                                            |
| --------------------------- | ----------------------------------------------------- |
| `DATABASE_URI`              | Строка подключения к MongoDB                          |
| `PAYLOAD_SECRET`            | Ключ шифрования Payload — `openssl rand -base64 32`   |
| `NEXT_PUBLIC_SITE_URL`      | Публичный адрес сайта                                 |
| `NEXT_PUBLIC_PAYLOAD_URL`   | Адрес Payload API                                     |
| `S3_ENDPOINT`               | Эндпоинт хранилища                                    |
| `S3_REGION`                 | Регион, по умолчанию `ru-central1`                    |
| `S3_BUCKET`                 | Название бакета                                       |
| `S3_ACCESS_KEY`             | Ключ доступа                                          |
| `S3_SECRET_KEY`             | Секретный ключ                                        |
| `NEXT_PUBLIC_S3_PUBLIC_URL` | Публичный префикс URL медиа                           |
| `RESEND_API_KEY`            | API-ключ Resend                                       |
| `CONTACT_EMAIL`             | Почта, куда падают заявки из форм                     |

| Команда                   | Описание                          |
| ------------------------- | --------------------------------- |
| `pnpm dev`                | Dev-сервер                        |
| `pnpm build`              | Продакшн-сборка                   |
| `pnpm start`              | Запуск продакшена                 |

```
├── lib/                     # payload.ts, toSlug.ts
└── payload.config.ts
```
