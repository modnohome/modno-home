# Modno Home

Интернет-витрина производителя модульных диванов: каталог моделей, страница каждого дивана с комплектацией и размерами, галереи фото и видео, формы заявок с отправкой на почту.

Сайт статический: `pnpm build` собирает обычные HTML/CSS/JS в папку `out/`, её содержимое заливается на любой хостинг с PHP (PHP нужен только для форм). Админки нет — весь контент лежит в JSON-файлах в папке `content/`.

Продакшн: [modnohome.ru](https://modnohome.ru)

## Стек

- **Next.js 16** (App Router, статический экспорт) + **React 19**
- **Tailwind CSS 4**, **TypeScript 5**
- **PHP** — `send.php`, обработчик форм на хостинге
- Медиафайлы, загруженные раньше через админку, и видео лежат в Yandex Cloud Object Storage — в контенте на них полные ссылки
- `keen-slider` — слайдеры, `yet-another-react-lightbox` — галерея

## Страницы

| Маршрут            | Что это                                |
| ------------------ | -------------------------------------- |
| `/`                | Главная: hero, каталог, видео, отзывы  |
| `/sofa/[slug]/`    | Страница модели дивана                 |
| `/privacy-policy/` | Политика конфиденциальности            |
| `/send.php`        | Приём заявок из форм → письмо на почту |

`robots.txt` и `sitemap.xml` генерируются при сборке.

## Контент

Все тексты, цены, телефоны и ссылки на видео — в `content/`:

| Файл                    | Что внутри                                                                         |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `content/settings.json` | Шапка (телефон, часы работы, видео, соцсети), подвал, политика, SEO и Яндекс Метрика |
| `content/home.json`     | Главная: hero, блок видео, каталог, отзывы, ткани                                  |
| `content/sofas/*.json`  | По файлу на каждый диван: название, цена, комплектации, размеры, видео            |

Как поменять контент: правишь JSON → `pnpm build` → заливаешь `out/` на хостинг.

- **Порядок карточек в каталоге** — список `sofasSection.selectedSofas` в `home.json` (адреса страниц диванов, например `"easy"`).
- **Адрес страницы дивана** получается из названия (`title`): `New York` → `/sofa/new-york/`.
- **Другие модели внизу страницы дивана** — список `relatedSofas` в файле дивана.
- **Блок «Короткие видео и описание»** — `showcase` в файле дивана: `title` (название), `specs` (список под названием: `label` выводится жирным, через тире `value`; пункт с пустым `value` не выводится) и `description` (текст под фото). Видео в блоке — первые три из `videos`.
- **Фото страницы дивана** лежат в `public/sofas/<folderName>/`, фото карточки — в `public/images/cards/<imageFilename>`. Диван без `folderName` — только карточка в каталоге, без своей страницы (как «Интерьерные кровати»).
- **Скрыть диван** — `"isActive": false`.
- **Политика конфиденциальности** (`footer.privacyPolicyContent` в `settings.json`) хранится в формате редактора Lexical, который был в старой админке: абзацы — это узлы `paragraph` с текстом в `children`.

## Формы заявок

Все формы отправляют `POST /send.php` (JSON). Скрипт отправляет письмо через PHP `mail()`. Типы заявок: обратный звонок, запрос каталога, расчёт стоимости, вопрос о тканях и цветах. Обязательное поле одно — телефон.

Адреса получателей и отправитель не хранятся в репозитории: на хостинге рядом с папкой сайта (уровнем выше `public_html`, не внутри) должен лежать `send-config.php` — образец в [send-config.example.php](send-config.example.php).

## Запуск

```bash
pnpm install
pnpm dev     # dev-сервер на localhost:3000 (формы локально не отправляются — нужен PHP)
pnpm build   # статическая сборка в out/
```

## Деплой

1. `pnpm build`.
2. Залить содержимое `out/` в корень сайта на хостинге (`public_html`), включая `.htaccess` — он включает HTTPS, убирает `www` и подключает страницу 404.
3. Один раз положить `send-config.php` уровнем выше корня сайта.

> Сборка на Windows: Next.js 16 кладёт служебные файлы для подгрузки страниц во вложенные папки вместо имён через точку ([vercel/next.js#92339](https://github.com/vercel/next.js/issues/92339)). `scripts/flatten-segments.mjs` в конце `pnpm build` раскладывает их по нужным именам; на Linux он ничего не делает.

## Структура

```
├── app/
│   ├── (frontend)/          # главная, страница дивана, политика
│   ├── robots.ts, sitemap.ts
├── content/                 # весь контент сайта (JSON)
├── components/
│   ├── sections/            # секции страниц
│   ├── ui/                  # кнопки, инпуты, карточки
│   ├── forms/               # формы заявок
│   └── common/              # модалки, RichText
├── public/                  # картинки, send.php, .htaccess
├── lib/                     # content.ts (чтение контента), toSlug.ts
└── scripts/                 # flatten-segments.mjs
```
